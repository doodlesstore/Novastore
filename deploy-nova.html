Deploy Nova Stone (NOVA)

Nova Stone NFT: 3,999 stones on BNB Smart Chain. First 300 mints FREE, then 0.0003 BNB per mint.

Rules locked in the contract after deploy:

  • MAX_SUPPLY 3,999; no per-wallet limit (the site states none).
  • Mint fee: first 300 mints FREE, but max 5 free mints per wallet — a wallet's 6th mint costs 0.0003 BNB even inside the first 300, and every mint from 301 on costs 0.0003 BNB. Fees are HELD in the contract — the owner collects them with the Withdraw step below (only the owner can withdraw). Network gas is separate and variable.
  • Personal wallets only (contract callers are rejected on-chain). No Agent ID gate: any personal wallet may mint, including wallets holding a Binance Agent ID. The site checks the connected wallet's Agent ID status in the Binance registry (0x60B9262456dE011F7d15a54CdD8c48bAaa8B022F) after connect and shows it (display only, not a gate).
  • No mining token: Nova Points / mining power live in the metadata and are an off-chain plan, not an on-chain token. mintedByWallet lets anyone read a wallet's minted count (leaderboard input).
  • tokenURI = baseURI + number + .json (meta files are N.json).
  • Mint is CLOSED by default — the owner opens it in step 4, only after baseURI is set.

Warning: this contract is unaudited. Try small amounts first. Deploy only from your own wallet in a dApp browser (OKX / MetaMask / Trust). Never send a seed phrase or private key to anyone.
